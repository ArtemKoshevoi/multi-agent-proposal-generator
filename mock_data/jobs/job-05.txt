Full Stack SaaS Developer
Summary
Project Overview:
I am seeking a highly skilled Full-Stack Developer to build and launch a proprietary SaaS platform. The design foundation has been built using Claude Design, and I am looking for a developer who leverages AI-native workflows (specifically Claude Code) to deliver high-quality software at speed.

This is a comprehensive project: I need someone to take this from the current design phase through to a fully functional MVP, including the successful onboarding of our first paying client.

Key Responsibilities:

The Build: Transform Claude Design artifacts into a production-ready SaaS application using Claude Code for efficient development and testing.

Infrastructure: Set up scalable hosting, secure database architecture, and automated CI/CD pipelines.

SaaS Features: Implement essential SaaS "plumbing"—user authentication, subscription/billing management (Stripe integration), and role-based permissions.

Launch & Onboarding: Provide technical support through the "Go-Live" phase, ensuring the platform is stable and bug-free for the first client.

Required Tech Stack & Skills:

AI-Native Workflow: Must be proficient in using Claude Code and LLMs to accelerate the dev cycle.

Frontend: React or Next.js (preferred for SEO/SaaS performance).

Backend: Node.js, Python, or a similar modern framework.

Database: Experience with PostgreSQL or similar, ensuring data isolation for a multi-tenant SaaS.

DevOps: Experience deploying to Vercel, AWS, or similar cloud environments.

Project Milestone & Success Criteria:
The project is not considered "complete" until the first client is active on the platform. This includes:

Completion of the functional MVP.

Successful deployment to a production environment.

Technical hand-holding during the first client's onboarding to ensure a seamless experience.

How to Apply:
Please describe your experience building SaaS products from scratch. Specifically, mention how you use AI tools like Claude Code to improve your delivery speed and code reliability.

Pro-Tips for this SaaS Launch:
The "First Client" Clause: Mentioning the first client in the contract is smart. It prevents a developer from handing you a "finished" app that crashes the second a real user tries to sign up.

Multi-Tenancy: Since this is a SaaS, ask the developer early on how they plan to handle data security between different clients. You want to make sure Client A can never accidentally see Client B’s data.

Analytics: Even for the first client, ensure you have basic event tracking (like PostHog or Mixpanel) so you can see exactly where that first user might be getting stuck.
